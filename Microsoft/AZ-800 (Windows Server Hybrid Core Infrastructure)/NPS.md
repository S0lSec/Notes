Network Policy Server is used to implement network-access authentication, authorization and accounting with any combination of the following functions:

# RADIUS Server
- NPS is the Microsoft implementation of a RADIUS server
- NPS enables the use of a heterogeneous set of wireless, switch, remote access or VPN equipment
# RADIUS Proxy
- When using NPS as a RADIUS proxy you can configure connection request policies
# RADIUS Accounting
- You can configure NPS to perform RADIUS account for user authentication requests
