# Explore Extended Detection & Response use cases
### Detection of Threat
Threat gets detected by IT team via alerts, defender, etc.
- Microsoft Defender for Endpoint
- Microsoft Defender for Cloud
### Remediation
Threat is remediated via automated remediation, security analyst approval of automated remediation or manual investigation of threat.
- Microsoft Defender for Endpoint
### Share Intelligence and Restore Access
Restore access to infected devices.
- Microsoft Defender for Office 365
- Microsoft Defender for Cloud
### Access Restricted
Access to resources is blocked due to the compliance status of the device.

Conditional access knows about device risk because of Microsoft Defender for Endpoint which notified Intune.
### Access Restored
Once the threat has been remediated and cleaned up. Access can be restored.

Microsoft Defender for Endpoint can trigger Intune to update Entra ID and Conditional Access to restore access.

## Triage and Automation
**Automation**
- Near real-time resolution of known incident types with automation.
- Well-defined attacks that the organisation has seen many times

**Triage (Tier 1)**
- Focus on rapid remediation of a high volume of well-known incident types that still require human judgement. 
## Investigation and Incident Management (Tier 2)
- Escalation point for issues from Triage
- Monitors alerts that indicate a more sophisticated attacker
- Can hunt using XDR tools in spare time
- Provides deeper investigation into a lower volume of more complex attacks

**Incident Management**
- Takes on the nontechnical aspects of managing incident including coordinating with other teams like communications, legal, leadership and other business stakeholders
## Hunt and Incident Management (Tier 3)
- Multi-disciplinary team focused on identifying attackers that could of slipped through the reactive detections and handling major business-impacting events.
- Hunts for undetected threats
- Assists with escalations and advanced forensics for reactive investigations
## Threat Intelligence
- Provides context and insights to support all other functions.
# Microsoft Security Graph
Provides a unified programmability model that you can use to access the data in 365, Windows and Enterprise Mobility + Security.

Offers a single endpoint https://graph.microsoft.com

Microsoft Graph exposes REST API and client libraries to access data on the following Microsoft cloud services:
- Microsoft 365 core services: Bookings, Calendar, Excel, Microsoft Lists, Microsoft Purview eDiscovery, Microsoft Search, OneDrive, OneNote, Outlook/Exchange, People (Outlook contacts), Planner, SharePoint, Teams, To Do, Viva Insights
- Enterprise Mobility + Security services: Microsoft Defender for Identity, Microsoft Entra ID, and Intune
- Windows services: activities, devices, notifications, Universal Print
- Dynamics 365 Business Central services
# Microsoft Graph Security API
Provides a single programmatic interface to connect multiple Microsoft Graph security providers.
Developers can use  the Security Graph to build security services.
