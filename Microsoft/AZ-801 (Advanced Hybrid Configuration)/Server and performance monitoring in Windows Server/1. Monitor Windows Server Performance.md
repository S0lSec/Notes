## There are 4 key hardware components monitor:
- CPU
- RAM
- Disk
- Network
## Tools to help with monitoring:
- performance monitor
- resource monitor
- reliability monitor
- Windows Admin Center
## Monitoring Methodology:
1. Predict when existing resources are to be used and use old analysis to determine when more resources are needed
2. Assess a servers workload and how much it can support. Plan to scale
3. Ensure your devices do not have bottlenecks (at least ones that slow performance)
4. Analyse the key hardware components
# Monitoring DNS
You can monitor the Windows Server DNS server role to determine the following aspects of your DNS infrastructure.
- General server statistics
- Dynamic updates
- Recursive lookups
- Zone transfers
# Monitoring DHCP
Monitor:
- Queue length
- How long it takes to process each packet
## Fixes to slow DHCP server
**80%/20% method**
Uses a 2 DHCP servers, both distributing different addresses to allowing faster processing.

**failover sever**
A 2nd server to be used in the case the main server is slowing down or fails.
# Monitoring VMs
VMs use all key hardware, be sure your server can supply the required resources.
