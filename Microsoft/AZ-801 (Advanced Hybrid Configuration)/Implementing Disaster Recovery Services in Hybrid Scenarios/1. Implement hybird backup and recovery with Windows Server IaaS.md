# Describe Azure Backup
Uses Azure resources for short-term and long-term storage to minimize or even eliminate the need for maintaining physical backup media.

 Automatic storage management, unlimited scaling, unlimited data transfer, data encryption and long-term retention.

At rest your data is encrypted and protected for you.

Includes security features such as **prevention**, **alerting** and **recovery**.
### Backup Types
- On-prem
- Azure VMs
- Azure File shares
- Microsoft SQL Server
- SAP HANA databases in Azure VMs and Microsoft Cloud
# Recovery Service Vaults
 A recovery service vault makes it easier to organise backup data while minimising management overhead.

Supports Data Protection Manager (DPM), Windows Server and Azure Backup Server
# Azure Backup Policies
Azure agent uses Microsoft Azure Recovery Services (MARS) agent to backup files, folders and system state from on-prem machines and Azure VMs.

These machines can backup directly to Recovery Services vault.
# Recover Windows IaaS VMs
There are multiple disaster recovery options available for VMs
### VM Backup
For backing up Azure VMs running production workloads, use Azure Backup.
- Supports application-consistent backups for both Win and Linux VMs
- Creates recovery points that are stored in geo-redundant recovery vaults
### Azure Site Recovery
Protects your VMs from a major disaster scenario when an entire region experiences an outage.
You can:
- Recover applications in minutes if configured
- Replicate to an Azure region of your choice
### Managed Snapshots
Provide a quick and simple option for backing up VMs that use Managed Disks.
A management snapshot:
- Is a read-only full copy of a managed disk
- Exist independent of the source disk and can be used to create new managed disks for rebuilding a VM
- Is billed based on the used portion of the disk
