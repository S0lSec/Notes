Azure backup allows for Azure and on-prem VMs to be backed up.

Backup maintains a copy of stateful data that allows you to go back in time. Site-recovery replicated data in real time and allows for a failover.

Backup -> Copy of data
Site-Recovery -> Replication of data in real time
# Restore Virtual Machine Data
### Create a new VM
Quick and gets a basic VM running from a restore point.
The new VM must be in the same region as the source VM
### Restore disk
Restores a VM disk, which can be used later to create a new VM.
### Replace existing
Restore a disk and use it to replace a disk on a existing VM
### Cross Region
Can be used to restore Azure VMs in the secondary region, which is an Azure paired region.
This feature is available for the options below:
- Create a VM
- Restore Disks
