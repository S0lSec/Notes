# Common Upgrade Methods

| Method                     | Description                                                                   | Best For                                                        | Key Considerations                                                                |
| -------------------------- | ----------------------------------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| In-Place Upgrade           | Upgrade directly on the same server, preserving roles, apps, and data.        | Minimal disruption; retaining existing setup.                   | Backup required; not ideal for complex roles; supported via ISO, UI, or SCONFIG.  |
| Clean Installation         | Fresh install of Server 2025, followed by manual migration of roles and data. | Starting fresh; resolving legacy issues.                        | Requires reconfiguration; time-intensive; ensures clean state.                    |
| Migration to New Hardware  | Move workloads to a new server running Server 2025.                           | Hardware refresh; physical to virtual (P2V); cloud transitions. | Use tools like Windows Server Migration Tools or Azure Migrate.                   |
| Cluster OS Rolling Upgrade | Upgrade cluster nodes one at a time without downtime.                         | Hyper-V or SOFS clusters needing high availability.             | Only supports one version jump at a time; may require intermediate upgrade steps. |
# Storage Migration Service
Can assign the identity of the source server to the target server, including the server name and IP address.

The general process of using storage migration service is:
1. Scan inventory of source servers
2. Transfer data
3. Transfer identity

**Orchestrator server** can run on Win Server 2019+ with 2CPU cores and 2GB mem
**Source servers** can run on Win Server 2003+ and Linux
**Destination servers** can run on Win Server 2012 R2+ with 2CPU cores and 2GB mem

For **security** the following firewall rules are required:
- SMB-In
- NP-In
- DCOM-In
- WMI-In
