# VM Scale Sets
Azure VM scale sets enable you to deploy and manage multiple load-balanced VMs. Allowing the amount of VMs to scale based on the demand.
# Implement load-balancing VMs
### Public load balancer
Provides outbound connections for VMs inside your VNet via NAT.
You the use public load balancers to load balance internet traffic to your VMs
### Internal load balancer provisions
Only private IPs are needed at the frontend.
You use internal load balancers to load balance traffic inside an VNet
### Frontend IP configuration
Used both private and public IP.
The IP address of your Azure Load Balancer is the point of contact for clients.
### Backend pool
Can be associated to VMs or VM scale set.
VMs in the backend pool serve the incoming requests
