# Microsoft Defender for Cloud
(Was formerly Azure Security Center)

Used to improve security posture in Azure.
Allows you to track compliance against regulatory standards and protect your environment and data.

Has various features to protect VMs.
# Implement and Assess Security Policies
## Remediate Security Recommendations
- Review more than how your ogs compares with security and compliance standards
- Tighten your security to meet those standards
- To access and apply security recommendations in the Azure portal, in Defender for cloud, select the Overall Secure Score tile.
## Run a vulnerability assessment against your Win Server IaaS VM
- Use Defender for Cloud to perform a vuln assessment on your VMs
- Must install a vulnerability assessment solution on the required resources.
# Microsoft Sentinel
Both a SIEM and a SOAR.

Collects data cross cloud-based and on-prem users, devices, apps and infrastructure.
Uses AI to identify suspicious activity.
## Implement SIEM functionality in Sentinel
- Enable Microsoft Sentinel
- Create a data connection
- Create a custom rule that generates an alert
## Best practices to implement SOAR in Sentinel
- When you create analytics rules that raise alerts, also configure them to create incidents
- Use the incidents to manage the investigation and response process
- Group related alerts into an incident
