# Application Security Groups
- Allows you to logically group network interfaces together.
- You can use ASG as a source or destination rule within a NSG.
- Without ASGs you will need to create a sperate rule for each VM
# Azure Firewall and Windows IaaS VMs
- Stateful firewall as a service
- Allows managing and controlling outbound network access
- Use NAT rules to manage inbound network access with Azure Firewall
# Windows Firewall with Windows Server
Windows Defender Firewall is a host-based firewall. It includes features such as firewall profiles and connection security rules.
# Choosing an Filtering Solution
**Outbound** - Use network + application rules
**Inbound** - NAT rules
# Network Watcher
Network watching is a regional service that lets you monitor and diagnose network conditions, in, to and from Azure.
