# Purview Audit
Used to understand how 365 is being used by capturing user and admin activity to support security, compliance and operational transparency.
### Standard
Included in 365 E3/E5/F1/F3 & Office 365 E1/E3/E5
- Enabled by default
- 180-day long retention
- Access through portal, PowerShell and API
- Export to CSV
### Premium
Requires 365 E5, E5 Compliance or relevant add-on
- Custom retention policies
- Default 1-year retention for core services
- Intelligent insights into activity patterns
- Higher API bandwidth for advanced integrations
## Roles
**Audit Reader**: Search and export only
**Audit Manager**: Search, export and manage audit settings
