# eDiscovery and Content search
### What are they?
**Content search** finds items across 365.
**eDiscovery** provides case-level tools for holds, structured review and controlled access.
### How do they work together?
**Content search** should be used for fast, targeted searches during investigations.
**eDiscovery** should be used when an investigation requires holds or coordinated review.
### When to use them?
**Content search** should be used in security investigations, HR or misuse inquires and incident response
**eDiscovery** should be used for legal or regulatory matters, subject rights requests, breach investigations requiring preservation.
# Required roles for Content Search
- **eDiscovery Manager**: Create and manage cases, search and export
- **eDiscovery Administration**: All Manager permissions and settings control
