Insider Risk Management uses additional data sources to identify risks that originate outside 365, such as HR events, physical access and endpoint activity.
### Integrations
- **Connectors**
	- HR events *(Add context to the investigation)*
	- Healthcare logs
	- Physical access data *(Add context to the investigation)*
- **Microsoft security solutions**
	- Defender for Endpoint & Cloud Apps *(Supports rapid detection and response)*
## Configuring HR Connector
**Requirements**
- **Data format**: HR systems must export data in CSV or JSON
- **Permissions**: Require the Data Connector Admin role
- **Authentication**: Uses an Entra ID app with client ID, secret and tenant ID

**Considerations**
- **Data freshness**: Regular updates ensure accurate signals
- **Compliance**: HR data must follow privacy requirements
- **Multiple connectors**: Indicators aggregate across all connected HR systems
## Configuring HealthCare Connector
**Requirements**
- **Data format**: EHR systems must export data in CSV, TSV or PSV
- **Permissions**: Require the Data Connector Admin role
- **Authentication**: Uses an Entra ID app with client ID, secret and tenant ID

**Considerations**
- **Regulatory sensitivity**: Healthcare data must follow strict privacy requirements
- **Activity types**: Detects self-access, colleague access or VIP patient access
- **Multiple connectors**: Indicators aggregate across all connected HR systems
## Configuring physical badging Connector
**Requirements**
- **Data format**: Badge systems must export JSON files that follow the required schema
- **Permissions**: Require the Data Connector Admin role
- **Authentication**: Uses an Entra ID app with client ID, secret and tenant ID

**Considerations**
- **Data ingestion**: It's recommended to post physical badging data daily
- **Multiple connectors**: Indicators aggregate across all connected HR systems
