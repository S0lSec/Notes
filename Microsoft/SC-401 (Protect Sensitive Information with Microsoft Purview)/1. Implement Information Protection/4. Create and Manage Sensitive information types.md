# Review classification and protection insights
Use Information Protection Reports to assess label adoption, classification trends and policy effectiveness.

Reports link to Data Explorer for labeled data and Activity Explorer for usage tracking.

- Review how sensitivity labels and sensitive information types are applied
- Check encryptions and data protection policies
- Review labeling changes, file access and DLP detections
- Ensure that labels and policies are applied correctly
- Access classification, labeling and policy performance data
