# Data classification overview
**Sensitive Information Types (SITs)**: Detect structured patterns
**Trainable classifiers**: Identify unstructured content by analysing meaning and context
# Classify data using sensitive information types
SITs identify structured data using predefined patterns such as credit card numbers and keywords.

SITs detect structured sensitive data, support labeling and protection and meet compliance needs by detecting regulated data.

They are used in information protection, data loss preventions and data lifecyle management.
# Classify data using trainable classifiers
Trainable classifiers identify unstructured content by analysing meaning and context instead of patterns or keywords.
### Types
**Pretrained classifiers** - Provided by Microsoft and read for common categories such as offensive language, resumes or source code.
**Custom trainable classifiers** - Trained by your org using real examples to identify unique content.
