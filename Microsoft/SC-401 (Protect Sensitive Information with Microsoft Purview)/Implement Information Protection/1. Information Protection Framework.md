# Know your Data
### 1. Describe the categories of sensitive information you want to protect
use sensitive information types (SITs) and trainable classifiers to identify and categories structured and unstructured sensitive data
### 2. Discover and classify sensitive data
Apply sensitive labels manually or automatically to classify and protect data with encryption, access, restrictions and visual markings.
Use data classification tools to detect, tag and monitor sensitive content.
### 3. View your sensitive items
Use data explorer, content explorer and activity explorer to analyse classified data, track label usage, and monitor user interactions with sensitive content.
