# Adaptive Protection
Adaptive protection adjusts DLP enforcement based on user risk levels so high-risk users receive stricter controls.

User insider risk management to assign, minor, moderate or elevated risk levels.
# DLP
## Enforce with file policies
File policies are policies applied to files (crazy). You create a policy which is then automatically applied to files matching the specified criteria.

File policies can be used in Defender for Cloud Apps to enforce DLP, detect sensitive data and apply protections across cloud apps.
## Analyse & Monitor
Use DLP analytics to identify data risks, recommended policies and refine existing protections.

Analyse and response to DLP policy violations by monitoring alerts and user activity in 365. Make use of the:
- Alert dashboard
- Activity explorer
