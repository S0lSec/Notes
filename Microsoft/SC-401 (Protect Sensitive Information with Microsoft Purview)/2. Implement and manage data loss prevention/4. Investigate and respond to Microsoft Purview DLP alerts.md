DLP alerts identify activity involving sensitive content, showing up in either Microsoft Defender XDR or Microsoft Purview.

## Configure DLP policies to generate alerts
![[Pasted image 20260914115601.png]]
- **Single-event alerts** trigger an alert each time a rule match occurs (high-sensitivity, low-volume)
- **Aggregate-event** alerts trigger when repeated matches occur within a short window (low-sensitivity, high-volume)
## Investigate DLP alerts
Using Microsoft Purview alerts remain available for 30 days in the DLP alerts dashboard.
Microsoft Defender XDR provides deeper investigation capabilities to correlate DLP activity with other security agents.
