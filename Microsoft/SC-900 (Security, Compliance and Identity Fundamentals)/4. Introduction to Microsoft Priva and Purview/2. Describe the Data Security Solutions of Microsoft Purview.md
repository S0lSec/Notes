# Data classification in Microsoft purview information protection
Identify important information across the estate and ensure that data is handled in line with compliance requirements.

Sensitive information types are pattern-based classifiers. They have set patterns that can be used to identify them.

Microsoft Purview includes built-in sensitive information types based on patterns that are defined by a regular expression or function.
Examples:
- Credit card numbers
- Passport or ID numbers
- Bank account numbers
- Health service numbers
# Sensitivity labels and policies
Sensitivity labels are available as part of information in the Microsoft Purview compliance portal. Organisations can use security labels to apply labels to content such as emails and documents similar to stamps.

Sensitivity labels can be configured to:
- Encrypt emails, meeting invites and documents
- Mark the content when office apps are used
- Apply the label automatically
- Protect content in containers such as Team, 365 groups, sharepoint
- Extend sensitivity labels to third-party apps and services
- Set the default sharing link type for sharepoint sites and individual documents
- Classify content without using any protection settings

Once sensitivity labels are created they need to be published to make them available to people and services in the organisations. This is done through label policies.

Sensitivity label policies allow admins to:
- Choose the users + groups that can see labels
- Apply a default label
- Require justification for label changes
- Require users to apply a label
- Link users to custom help pages

# Microsoft Purview Insider Risk Management
Helps organisations to identify, investigate and address internal risks such as data leaks, intellectual property theft, fraud, insider trading, etc.

Insider risk management workflow:
- Create policies to define what risk indicators are examined
- Alerts automatically generated by risk indicators that match policy conditions
- Triage alerts with a needs review status
- Cases are created for alerts that require deeper review and investigation
- Reviewers can quickly take action to resolve the case
# Adaptive Protection
Adaptive protection in Microsoft Purview uses machine learning to identify the most critical risks and proactively and dynamically apply protection controls.

Based on risk Insider Risk Management, Adaptive Protection in Microsoft Purview applies controls from:
- DLP
- Microsoft Purview Data Lifecycle Management
- Microsoft Entra Conditional Access

Mitigate potential risks by using:
- Context-aware detection
- Dynamic controls
- Automated mitigation
