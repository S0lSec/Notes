# SIEM and SOAR
## SIEM
- Collects data from across the whole digital estate
- Analyses and looks for correlations or anomalies
- Generates alerts and incidents
## SOAR
- Takes alerts from many sources, such as SEIM systems
- Triggers action-driven automation workflows and processes
- Runs security tasks that mitigate the issues
# Sentinel
- Sentinel is a SIEM and a security platform
- Provides a unified view of threats
- Supported end-to-end security operations
