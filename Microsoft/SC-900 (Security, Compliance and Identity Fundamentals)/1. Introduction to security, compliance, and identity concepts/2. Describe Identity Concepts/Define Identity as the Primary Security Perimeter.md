# Traditional Security Perimeter
If everything is inside of one office using a **network perimeter** (a defined boundary, enforced by firewalls and VPN gateways, around corporate systems) is viable.

That environment is no longer most organisations.
# Identity as the new security perimeter
If you can't reliably control who/what is on your network, you will now use **identity** to set the security boundary.

# Types of identities
- **Human Identities**: People
- **Device Identities**: Hardware
- **Workload Identities**: Software, applications and services
- **Agent Identities**: AI
# Four Pillars of Identity Infrastructure
- **Administration**: Creation, management and governance of identities
- **Authentication**: Verifying identity
- **Authorization**: Determine what an authentication identity is allowed to do
- **Auditing**: Monitoring who did what, when and from where
