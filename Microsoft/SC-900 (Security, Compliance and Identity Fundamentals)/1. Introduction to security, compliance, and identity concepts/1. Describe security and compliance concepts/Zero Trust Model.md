# Zero Trust Guiding Principles
- Verify explicitly
- Use least privileged access 
- Assume breach
# Seven Foundational Pillars
- **Identities**: Verify any attempt to access resources
- **Devices**: Monitor devices for health status and compliance
- **Applications**: Have visibility into all applications being used in your environment, including unsanctioned applications
- **Data**: Should be classified, labeled and encrypted based on its attributes and sensitivity
- **Infrastructure**: Continuously assessed for version currency, configuration compliance and unusual behavior.
- **Networks**: Should be segmented
- **Visibility, automation and orchestration**: Manage the massive influx of data that the other layers provide
