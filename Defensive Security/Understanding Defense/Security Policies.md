# Business Policies
Guidelines that are developed by an org to govern its actions.
### Company Policies
- Establish rules of conduct and the responsibilities of both employees and employers
- Protect the rights of workers as well as the business interests of the employers
### Employee Policies
- Identify employee salary, pay schedule, employee benefits, work schedule, vacations, etc.
- Often provided to new employees to review and sign
### Security Policies
- Security objectives for a company
- Objectives, rules and requirements to collectively ensure security
- Contently evolving

# Security Policies
Used to inform users, staff, and managers of an orgs requirements for protecting technology and information assets.
### Identification and Authentication Policy
- Specified authorisation people that can access network resources and identify verification procedures
### Password Policies
- Ensures passwords meet minimum requirements and are changed regularly
### Acceptable Use Policy (AUP)
- Identifies network applications and uses that are acceptable to the orgs
- May also identify ramifications if this policy if violated
### Remote Access Policy
- Identifies how remote users can access a network and what is accessible via remote connectivity
### Network Maintenance Policy
- Specified network device operating systems and end user application update procedures
### Incident Handling Procedures
- Describes how security incidents are handled

# BYOD Policies
Used to protect the org while allowing employees to use their own devices
### Password Protected Access
- Use unique passwords for each device and account
### Manually Control Wireless Connectivity
- Turn off Wi-Fi and Bluetooth connectivity when not in use
- Connect only to trusted networks
### Keep Updated
- Always keep the device OS and other software updated
### Backup Data
- Enable backup of the device in case it is lost or stolen
### Enable "Find my Device"
- Subscribe to a device locator service with remote wipe feature
### Use Mobile Device Management (MDM) Software
- MDM software enables IT team to implement security settings and software configs on all devices that connect to company networks

# Regulatory and Standards Compliance
Network security pros must be familiar with the laws and code of ethics that are binding on Information Systems Security (INFOSEC) pros.
