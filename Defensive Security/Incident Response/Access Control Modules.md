## Discretionary Access Control (DAC)
- Least restrictive model
- Allows users to control access to their own data
- May use ACLs or other methods to specify which users or groups users have access to the info
## Mandatory Access Control (MAC)
- Applied the strictest access control
- Typically used in military missions
- Assigns security level labels to information and enables users with access based on their security level clearance
## Attribute-Based Access Control (ABAC)
- Based on attributes of the object to be accessed, such as:
	- Time of day
	- User accessing the resource
	- Environmental factors
## Role-Based Access Control (RBAC)
- Access decisions are based on roles and responsibilities within the org
- Different roles are assigned security privileges
- Roles may include different positions, job classifications or groups of job classifications
## Rule-Based Access Control (RBAC(wat?))
- Network security staff specify sets of rules regarding or conditions that are associated with access to data or systems
- These rules may specify permitted or denied IP addresses, or certain protocols and other conditions
## Time-Based Access Control (TAC)
- Allows access to network resources based on time of day
