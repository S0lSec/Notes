The Incident response plan must be proactive and executed as soon as an attack is suspected.

Some examples of incident indicators:
- Exploitation has occurred 
- Malware detection 
- Change in files and configuration 
- Unauthorised use of credentials 
- System crashes 
- Deviation in traffic

## Red teaming exercise
Experienced professionals will execute a risk-based technique that will assess every weakness and explore areas of vulnerabilities that can cause any potential damage.

After an assessment, a thorough report will be created, further referred to the organisations management to develop a plan to mitigate the possible risks.

Some possible red-team testing techniques are:
- On-site or off-site reconnaissance
- Penetration testing (internal, external, and physical)
- Monitoring security controls
- Intrusion to gain access
- Remote network access
- Disable security alarms
- Social engineering
- Phishing tests
