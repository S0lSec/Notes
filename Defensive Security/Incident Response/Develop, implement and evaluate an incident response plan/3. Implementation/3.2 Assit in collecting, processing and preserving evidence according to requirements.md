Every person who handles any proof must ackowledge that a chain of custody should not be broken to make the evidence preservation successful.

The record should be continuous and held safely and secure as digital evidence is volatile, fragile and can easily be altered.

The collection process of evidence should be as transparent and detailed as possible.
Many tools can be used to collect evidence when an incdent happens, as mentioned below:
- Audio and video recorders 
- Storage equipment's 
- Portable printing 
- Forensic software's 
- Disk images using backup devices 
- Packet sniffers and analysers 
- Logfile preservation (Chain of custody forms)

### Avoid at any cost
Evidence is fragile and can easily be destroyed, so make sure you do not power down until evidence is collected successfully.

Do not run programs that can modify time and date, hampering the chain of custody.
### Privacy and legal consideration
You must adhere to the organisations privacy guide as private information can reveal personal files.

Evidence needs to be admissible, authentic, complete and relaible.
### Modification, access and creation
It is essential to know when a file was created, utilised or manipulated.

Not all data collection methods can preserve file times..
The most used timestamps are:
- Modification time
- Access time
- Creation time
## Prioritising data collection
Data that is less likely to change can be collected later. Volatile data should be collected first, as follows:
1. Network connections
2. Login sessions 
3. Contents of memory
4. Running processes
5. Open files
6. Network configuration
7. Operating system time
