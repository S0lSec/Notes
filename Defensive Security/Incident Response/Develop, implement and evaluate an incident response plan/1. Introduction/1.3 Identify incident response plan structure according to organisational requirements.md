## The key elements to establish a successful incident response plan
- Corporate culture and environment
- Security team
- Executives
- Stakeholders
- Dependent variables
# Forming an incident response capability should include the following actions
- Crafting an incident response policy plan
- Improving procedures for performing incident handling and reporting
- Setting guidelines for communicating with outside parties involving incidents
- Choosing a team arrangement
- Forming relationships and connections between the incident response team and other groups
- Establishing what services the incident response team should provide
- Staffing and training the incident response team

## The key recommendations to structure an incident response plan are
- Determine a proper incident response capability
- Developing an incident response policy
- Create an IR plan based on the IR policy
- Develop incident response procedures
- Establish polices and procedures on incident information sharing
- Consider the appropriate elements when choosing an incident response team model
- Select individuals with appropriate skills for the IR team
