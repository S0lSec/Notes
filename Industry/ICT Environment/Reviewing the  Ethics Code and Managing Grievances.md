# Key Concepts
- **Review Procedure:** A structured method for evaluating processes or behavior
- **Grievance Process:** A formal way for staff to raise concerns
- **Feedback Response:** Adjusting documents based on staff input
# Creating review procedures
Review procedures must be clear and strucutred
# Documenting review outcomes
Recording outcomes supports transparency
- Provides summaries
- List recommendations
# Purpose of grievance procedures
Grievance steps allow staff to raise concerns safely
- Provide a fair process
- Encourage open communication
# Developing grievance steps
Clear steps help staff understand how to act
- How to lodge a concern
- Who to contact
# Distributing updated procedures
Procedures must be shared with all relevant staff
- Add to policy platforms
- Discuss in meetings
- Include handbooks
# Seeking feedback from staff
Feedback highlights areas that need improvement
- Ask for suggestions
- Review challenges raised
# Responding to feedback
- Improvement occurs when feedback is acted on
- Clarify unclear instructions
- Update confusing sections
# Workplace example: Grievance
- Staff raise concerns about long grievance steps
- Review process identifies unclear wording
