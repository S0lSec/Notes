# Industrial Control Systems (ICS)
Command and control (c2) network and systems designed to support industrial processes, such as:
- Power rplants
- Public transportation
- Airports

Provide automated, regular operation and monitoring performance
## Kinds of ICS
- Supervisory control and data acquisition (SCADA)
- Distributed Control Systems (DCS)
# SCADA
**Supervisory Control And Data Acquisition**
## Major elements of SCADA
- Process/system/machinery to monitor and control
- A monitoring and control system
## When is SCADA needed?
- A system needs uninterrupted power
- A systems needs a protected environment
- A complex system status needs monitoring in real time
- Equipment at remote locations need monitoring and controlling
## How does SCADA help?
- Data tracking in real-time and historically
- Problem detection and prediction
- Targeting and eliminating bottlenecks and inefficiencies
- Controlling larger, complex processes with lesser manpower
## How does SCADA function?
- Data acquisition
- Data communication
- Data presentation
- Data control
# PLC vs RTU
**Programmable Logic Controller** vs **Remote Terminal Unit**
## PLC
- Anything can be programmed
- Everything has to be programmed
- Steep learning curve
## RTU
- Built-in intelligence
- Firmware upgrades for new functions
- Configure without programming
- Easy learning curve
# ICS Components
- IED - Intelligent Electronic Device
	- Monitors power usage by bigger machines
- RTU - Remote Terminal Units
	- Uses microprocessor to connect objects to an automated system
- PLC - Programmable Logic Controllers
	- Reggedized computer for industrial automation
- DCS - Distributed Control System
	- System of sensors, controllers and associated computers that are distributed throughout a plant
- HMI - Human Machine Interface
	- User interface that connects a person to a machine
- SCADA - Supervisory Control and Data Acquisition
