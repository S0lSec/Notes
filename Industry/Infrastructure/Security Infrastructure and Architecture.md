**Security Architecture** refers to the design, description and specification of the elements, components, structure and interrelationships that contribute to the protection of information assets within an organisation. Its all-embracing to ensure that digital and informational assets are adequately protected.

It is the foundation of any IT project, blueprint for cybersecurity measures and alignment with business objectives and requirements.

**Security Architecture:**
- Provides protection against threats
- Ensures compliance
- Provides design and controls for business continuity
- Reduces reputational damage
# Network Security Architecture 
- **Physical** security controls prevent unauthorised physical access
- **Technical/Data** security controls prevent unauthorised access to network data
- **Administrative** security controls provide consistency in security operations
## Access Control
Security process that controls who or what can view, enter or use resources.

| **Key Elements**                     |                                                                                                                                                                            |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Firewall Protection                  | Controls incoming and outgoing network traffic with predetermines rules.                                                                                                   |
| Network Access Control (NAC)         | Controls the devices suitability before access to the network is provided                                                                                                  |
| Identity and Access Management (IAM) | Controls and manages the asset identities and user access to data systems and resources over the network.                                                                  |
| Load Balancing                       | Controls the resource usages to distribute tasks over a set of resources and improve overall data processing performance.                                                  |
| Network Segmentation                 | Creates and controls network ranges and segmentation to isolate the users access levels, group assets with common functionalities and improve the protection of resources. |
| Virtual Private Networks (VPN)       | Creates and controls encrypted communication between devices over the network.                                                                                             |
| Zero Trust Model                     | Suggests configuring and implementing the access and permissions at a minimum level.                                                                                       |
## Threat Control
The methods, policies and technical safeguards used to detect, manage, prevent and mitigate risks or security threats against assets.

| Key Elements                                          |                                                                                                                                                                                                    |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IDS/IPS                                               | Inspects the traffic and creates alerts or resets the connection when detecting an anomaly/threat.                                                                                                 |
| Data Loss Prevention                                  | Inspects the traffic content and block the extraction of sensitive data                                                                                                                            |
| Endpoint Protection                                   | Protecting all kinds of endpoints and appliances that connect to the network by using multi-layered approach like encryption, antivirus, antimalware, DLP and IDS/IPS                              |
| Cloud Security                                        | Protecting cloud/online-based system resources from threats and data leakage by applying suitable countermeasures like VPN and data encryption                                                     |
| Security Information and Event Management (SIEM)      | Technology that helps threat detection, compliance and security incident management, through available data by using event and context analysis to identify anomalies, threats and vulnerabilities |
| Security Orchestration Automation and Response (SOAR) | Technology that helps coordinate and automate tasks between various people, tools and data within a single platform to identify anomalies, threats and vulnerabilities.                            |
