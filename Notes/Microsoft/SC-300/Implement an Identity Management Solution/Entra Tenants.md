# Roles
- Define access to resources
- Do not overlap with Azure roles by default
## Using roles for Common Delegation Scenarios
- Restrict and manage application creation
- Assigning owners to an application
- Assigning a built-in administrative role that grants access to manage config in Entra ID
- Creating custom role for defining specific permissions
# Administrative Units
- Resources that can be containers for other Entra resources
- An administrative unit can contain only users, groups and devices
- Administrative units restrict permissions in a role to specific portion of your organisation that you define

## Common delegation scenarios for Admin Units
- Assigning types of authentication methods
- Creating dedicated Helpdesk admin
- Admin to control users and groups within the admin unit
