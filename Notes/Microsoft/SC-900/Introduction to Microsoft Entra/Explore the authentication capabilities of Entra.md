## Authentication methods of Entra
- Passwords and phone-based methods are legacy approaches
- Modern authentication methods improve security and usability
- Microsoft recommends moving towards passwordless authentication
- Phishing-resistant methods offer the strongest protection
## Self-Service Password Reset (SSPR)
#### Benefits of SSPR
- Administrators can change settings to accommodate new security requirements
- Saves the organisations money by reducing the number of calls and requests to help desk staff
- Increases productivity, allowing the user to return to work sooner
#### SSR works in the following scenarios
- Password change + reset
- Account unlock
#### Authentication methods of SSPR
- Mobile app notification
- Mobile phone
- Mobile app code
- Email
- Office phone
- Security questions
