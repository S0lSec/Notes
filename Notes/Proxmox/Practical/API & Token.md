# API Tokens
## Create API Token
1. Go to Datacenter > Permissions > API Tokens
2. Click Add
3. Select User
4. Add token ID
5. Check Privilege Separation
6. Click Add
![[Pasted image 20260508120931.png]]
## API Token Permissions
1. Go to Datacenter > Permissions
2. Click Add > API Token Permissions
3. Select a Path (`/` as a path applies permissions to entire cluster)
4. Select user and role
5. Click Add
